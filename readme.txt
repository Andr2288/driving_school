DriveSchool — коротка інструкція для запуску
============================================

ЩО ПОТРІБНО ВСТАНОВИТИ (один раз)
---------------------------------

1) Node.js
   Завантажте і встановіть з офіційного сайту:
   https://nodejs.org/
   Оберіть версію LTS (кнопка зліва).
   Під час встановлення залишайте налаштування за замовчуванням.
   Після встановлення перезавантажте комп’ютер.

2) XAMPP (потрібен для бази даних MySQL)
   Завантажте і встановіть:
   https://www.apachefriends.org/
   Після встановлення запустіть "XAMPP Control Panel".

3) WebStorm (програма для роботи з проєктом)
   Завантажте і встановіть:
   https://www.jetbrains.com/webstorm/download/


ЯК ВІДКРИТИ ПРОЄКТ У WEBSTORM
-----------------------------

1) Запустіть WebStorm.
2) Натисніть Open / Open Folder.
3) Оберіть папку "project" (там є папки backend і frontend).


ЯК ВІДКРИТИ ТЕРМІНАЛ У WEBSTORM
-------------------------------

Гарячі клавіші (Windows):
  Alt + F12

Або через меню:
  View → Tool Windows → Terminal

Важливо: для цього проєкту потрібні ДВА термінали одночасно
(один для сервера, один для сайту).


КРОК 1. ЗАПУСТИТИ БАЗУ ДАНИХ (XAMPP)
------------------------------------

1) Відкрийте XAMPP Control Panel.
2) Навпроти MySQL натисніть Start.
3) Має з’явитись зелений індикатор (MySQL запущений).


КРОК 2. СТВОРИТИ БАЗУ ДАНИХ (один раз)
--------------------------------------

1) У WebStorm відкрийте термінал (Alt + F12).
2) Перейдіть у папку backend. Для цього введіть команду і натисніть Enter:

   cd backend

3) Встановіть залежності, які ще не встановлені. Для цього виконайте команду:

   npm install

4) Запустіть меню налаштування бази:

   npm run db:setup

5) У меню введіть цифру і натисніть Enter:
   3  — Перевстановити базу даних (найпростіший варіант для першого запуску)
   1  — Перевірити стан (має показати по 16–20 записів у кожній таблиці)
   0  — Вихід

Після пункту 3 база "driving_school" буде створена з тестовими даними.


КРОК 3. ЗАПУСТИТИ СЕРВЕР (backend)
----------------------------------

1) У тому ж терміналі переконайтесь, що ви в папці backend.
2) Виконайте:

   npm run dev

3) Має з’явитись повідомлення приблизно такого вигляду:
   Сервер запущено: http://localhost:3001

Цей термінал НЕ ЗАКРИВАЙТЕ, поки користуєтесь сайтом.


КРОК 4. ЗАПУСТИТИ САЙТ (frontend)
---------------------------------

1) Відкрийте ДРУГИЙ термінал у WebStorm:
   натисніть "+" у вікні Terminal (новий термінал).
2) Перейдіть у папку frontend:

   cd frontend

3) Встановіть залежності, які ще не встановлені. Для цього виконайте команду:

   npm install

4) Запустіть сайт:

   npm run dev

5) У терміналі з’явиться адреса, зазвичай:
   http://localhost:5173/

6) Відкрийте цю адресу в браузері (Chrome / Edge).


ЯК ЗУПИНИТИ ПРОГРАМУ
--------------------

1) У терміналі з сервером натисніть Ctrl + C.
2) У терміналі з сайтом натисніть Ctrl + C.
3) У XAMPP можна натиснути Stop біля MySQL.
